02 / WHY RAG

為什麼需要 RAG？

外部知識

可以補充資料庫中的相關資訊，而不只依賴模型參數內的知識。

降低 Hallucination

由相關資料作為生成依據，使回答更容易保持事實性與可驗證性。

適合知識密集任務

尤其適合需要特定、經常變動或較不常見知識的問題。

04 / PREPARATION

Document Preparation 與 Chunking

Document Preparation

準備外部資料

蒐集並整理一個可供檢索的文字資料庫，例如報告、文件或知識庫文章。

→
Chunking

切成較小的 Passage

將文件分成較小的 text chunks / passages，讓 Retriever 能處理與比對這些文字片段。

初學者重點：Chunking 的目的是讓搜尋單位變得明確；Wiki 沒有提供具體的 chunk size、overlap 或切分演算法，因此簡報不自行指定。

資料品質與切分品質會影響後續 RetrievalWiki Source：RAG Survey / Knowledge-Intensive RAG · 4 / 10
05 / SEARCH

Indexing 與 Retrieval

Indexing

建立可搜尋的知識庫

將準備好的文字放入可檢索的 external database 或 passage collection。

Retrieval

找出相關資訊

輸入問題後，Retriever 從資料庫找出最相關的文件或 passages。

❓

不是每個問題都需要檔案中的所有資訊

傳統 RAG 可能固定檢索一組文件；進階方法會依問題決定「是否需要 Retrieval」及何時再次檢索。

檢索失敗會直接影響後續生成品質Wiki Source：CRAG / Self-RAG · 5 / 10
06 / ANSWER

Augmentation 與 Generation

Augmentation

把檢索內容交給 LLM

將使用者問題與 Retrieved passages 一起放入 Language Model 的輸入。

+
Generation

依外部資料產生回答

Language Model 根據問題及外部 context，生成 grounded、較可驗證的答案。

關鍵觀念

Retrieved context 是證據來源；Generation 是整合證據的產出過程。即使檔案被找到，模型仍可能誤用或忽略內容。

07 / FAILURES

RAG 常見 Failure Points

1

檢索錯了找到無關或不準確的文件。

2

固定檢索太多與問題無關的 passage 可能干擾生成。

3

Context 未被善用模型忽略證據或未與 Retrieved context 一致。

4

仍會 Hallucinate答案即使有 Retrieval，也未必完全來自支援證據。

5

Context 太長或太雜會降低重點資訊與長文本中的有效利用。

6

外部知識本身有錯Retriever 找到的資料可能是不準確或低可靠度資訊。

RAG 的可靠性取決於每個階段是否都正確Wiki Source：CRAG / Self-RAG / RAGAS · 7 / 10
08 / ADVANCED RAG

CRAG 與 Self-RAG 如何改善傳統 RAG？

CRAG

檢索後做修正

使用 Retrieval Evaluator 評估 Retrieved documents 的品質與可靠度。

  • 結果足夠：保留並精煉
  • 結果不正確：尋找其他知識來源
Self-RAG

檢索與生成都會自我反省

透過 Reflection / Critique 概念判斷：

  • 是否需要 Retrieval
  • Passage 是否相關
  • 回答是否由 Passage 支援

共同改善：傳統 RAG 常無差別檢索；CRAG 與 Self-RAG 都希望讓檢索與使用外部知識更具選擇性。

兩者都強調「不是每次都檢索，也不是檢索後就直接照用」Wiki Source：CRAG / Self-RAG · 8 / 10
09 / EVALUATION

RAGAS 如何評估 RAG？

1

Faithfulness

生成的 claims 是否有 Retrieved context 支援？

2

Answer Relevance

答案是否真正回答了使用者問題？

3

Context Relevance

檢索到的 context 是否聚焦且足夠？

Reference-free 評估

不一定依賴人工標註答案，可加速 RAG 開發與評估。

WikiEval

提供 question–context–answer triples，以及 Faithfulness、Answer Relevance、Context Relevance 的人工判斷。

需要同時評估 Retriever、LLM 與整體回答品質Wiki Source：RAGAS / WikiEval · 9 / 10
